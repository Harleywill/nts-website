Google Reviews Integration - Design Summary

Complete design for hybrid testimonials + reviews section

✓ What You're Getting

  • Homepage: Keep your testimonials carousel + add new "Verified Reviews from Google" section below
  • Review Cards: Top 3 reviews displayed as clickable cards (5-star ratings, reviewer name, review text)
  • Links: Each review card links directly to Google Business profile
  • Admin Control: Manage which 3 reviews appear via admin dashboard
  • No API dependency: Manual data entry = simpler, no refresh tokens to manage

🌐 User Flow

  1. Visit NTS homepage
  2. Scroll down past testimonials
  3. See "Verified Reviews from Google"
  4. Click any review card
  5. Redirected to Google Business profile
  6. See full review + all other reviews

⚙️ Admin Flow

  1. Log into admin dashboard
  2. Go to "Reviews" section
  3. Add/edit 3 reviews (name, text, rating, Google link)
  4. Save
  5. Reviews appear on homepage immediately
  6. No rebuild needed

📊 Data Model

New "GoogleReview" table in your database:

id: Int (auto-increment)
reviewerName: String
reviewText: String
rating: Int (1-5)
googleReviewUrl: String
reviewerTitle: String (optional - "Local Guide", "381 reviews", etc.)
featured: Boolean (to control which reviews show)
order: Int (sort order)
createdAt: DateTime
updatedAt: DateTime
